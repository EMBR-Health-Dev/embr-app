# Acquisition Readiness — Control Document

This is not a claim that EMBR is "acquisition ready." It is a control
document: what is verified, what remains open, and who needs to supply
the missing evidence. Every VERIFIED row below was checked directly
against the repository, production configuration, deployment history,
or test runs on 2026-09-25 — not carried over from an earlier
document's claim about itself. Where a claim can only be confirmed by
someone outside engineering (legal, clinical, financial, corporate),
it is marked accordingly and left open, not guessed at.

**Status values used throughout:**

- `VERIFIED` — directly checked against running infrastructure, source
  code, test output, or an existing engineering document, on the date
  noted.
- `NEEDS FOUNDER INPUT` — requires a fact only the founder has (an
  agreement, a policy decision, a business record).
- `NEEDS ENGINEERING VERIFICATION` — a real engineering task, not yet
  done (e.g. an untested restore, an unconfirmed live integration).
- `NEEDS EXTERNAL / LEGAL VERIFICATION` — requires counsel, an
  auditor, a regulator, or another outside party.
- `NOT YET APPLICABLE` — no current claim is being made in either
  direction; nothing to verify yet.

Documentation existing does not by itself make a row VERIFIED — every
VERIFIED row below cites what was actually checked, not just what a
doc says.
